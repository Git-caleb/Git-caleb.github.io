# 11. Container With Most Water
## Description
You are given an integer array `height` of length `n`. There are n vertical lines drawn such that the two endpoints of the `ith` line are `(i, 0)` and `(i, height[i])`.
Find two lines that together with the x-axis form a container, such that the container contains the most water.
Return the maximum amount of water a container can store.
**Notice** that you may not slant the container.

Example 1:
```
Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
```
**Example 2:**
```
Input: height = [1,1]
Output: 1
```
**Constraints:**
- 2 <= height.length <= 10^5
- 0 <= height[i] <= 10^4

## Approach
The brute-force approach (checking all pairs of lines) would result in O(n²) time complexity, which is inefficient for large input sizes (up to 10^5 elements). The optimal solution uses a two-pointer technique:
Initialize two pointers, `left` at the start (index 0) and `right` at the end (index n-1) of the array.
Calculate the area of the container formed by the two pointers: `area = min(height[left], height[right]) * (right - left)`.
Keep track of the maximum area encountered during the iteration.
Move the pointer pointing to the shorter line inward (since moving the taller line inward cannot increase the area, as the height of the container is limited by the shorter line, and the width decreases).
Repeat steps 2-4 until the two pointers meet.
This approach ensures we only traverse the array once, leading to linear time complexity.

## Solution
```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left = 0
        right = len(height) - 1
        max_area = 0
        while left < right:
            # Calculate current area
            current_width = right - left
            current_height = min(height[left], height[right])
            current_area = current_width * current_height
            # Update max area
            if current_area > max_area:
                max_area = current_area
            # Move the shorter pointer inward
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return max_area
```
## Complexity Analysis
- **Time Complexity**: O(n) - We traverse the array exactly once with the two pointers, where n is the length of the height array.
- **Space Complexity**: O(1) - We only use a constant amount of extra space (for pointers and max area variable), with no additional data structures used.
